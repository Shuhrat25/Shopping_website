# Shopping Website — учебный интерфейс магазина

Статический frontend-прототип интернет-магазина, созданный для университетского проекта. Показывает вёрстку каталога, навигации, карточек товаров и административного интерфейса.

[Открыть демо](https://shopping-website-nine-tawny.vercel.app/)

## Технологии и структура

HTML, CSS и JavaScript; исходные страницы — `index.html` и `admin.html`, стили, скрипты и изображения находятся в `assets/`.

## Статус

Проект демонстрирует интерфейс магазина. Реального оформления и оплаты заказов, серверной авторизации и общей базы товаров в репозитории нет. Отображаемые товары и показатели используются как примеры.

## Запуск

Откройте `index.html` или отдавайте папку любым статическим сервером:

```bash
python -m http.server 8000
```

Главная страница: `http://localhost:8000/`; административный макет: `/admin.html`. Сборка и npm не требуются.
